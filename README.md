# SpaceXRepository

 

##  Description
**SpaceX Repository** is a Java library for managing information about missions and rockets through SpaceXRepository class
It allows creating, storing, and retrieving mission and rocket objects, along with handling exceptions and statuses.

The project follows a repository-based architecture combined with object factory patterns.  
It also includes a full set of unit tests to verify correct functionality.

##  Running the Project

### 1. Requirements
- **Java 17+**
- **Maven 3.8+**

### 2. Compile and Run Tests
```bash
mvn clean install
```
### Usage
Use SpaceXRepository as this class is supposed to maintain all the logic required to add Mission, Rocket, assign Rocket(s) to Mission and return summary.
You can create default Mission and Rocket using their corresponding factory classes.
